## 网络日志

默认情况下，Puppeteer 会监听所有网络请求和响应，并在 page 上发出对应的网络事件。

```ts
const page = await browser.newPage();
page.on('request', request => {
  console.log(request.url());
});

page.on('response', response => {
  console.log(response.url());
});
```
